RIH Care Insight Assistant: system architecture

Independent student prototype · synthetic data · loopback only · $0 local stack

Clients

Student browserChat, conversation history, resource directory. Anonymous owner cookie; conversations expire after 24 h.
Staff browserSources, governance, observability, feedback, users, audit log, ingestion. Reviewer or admin session.
HTTP on 127.0.0.1

Frontend container · nginx (non-root, read-only)

React 19 + TypeScript SPABuilt with Vite; strict Content Security Policy; light and dark themes.
Reverse proxyOnly /api is forwarded; the API has no published port.
/api/v1 · internal network, no internet route

Backend container · FastAPI (non-root, read-only)

Request guards: request ID · body limit · security headers · CSRF + Origin check · rate limits

Student chat turn

1Deterministic safety routerCrisis, Title IX, conduct; 12-language lexicon; runs on the original text before anything else.
2Decline and guidanceRespectful alternatives; counseling and retention templates.
3PlannerRule planner by default. Optional Strands agent on a loopback Ollama model proposes tool calls only.
4Governed tool executorRegistry, strict arguments, Policy-as-Code (default deny), budgets, timeouts, output checks.
5Governed RAGInventoried, approved, unexpired sources with matching SHA-256; hybrid BM25 + trigram ranking.
6Cited answerCitations checked against this turn's evidence; text composed from tool outputs only.
Fixed safety guidanceCrisis, Title IX and conduct messages stop here: no planner, no tools, no model. Still returned if storage or retrieval fails.

Staff operations

Staff authscrypt hashes, lockout, 8 h sessions
RBAC policypolicy/authorization.json, deny overrides allow
Source reviewDecisions bound to content hashes; ingestion stays pending
Risk register and readinessNIST AI RMF aligned; release decisions need a person
Audit logPolicy and security events with salted principal hashes

Data

SQLiteSessions and messages (owner-bound), staff accounts, audit events, source reviews, risk and release decisions, incidents.
Versioned in gitSynthetic knowledge base and source inventory, authorization policy, risk register and controls, red-team scenarios, evidence.

Observability

OpenTelemetrySpans per request, chat turn and tool call; metrics for latency, tools, lanes and security events.
Privacy allowlistsNo message text, arguments, usernames or client addresses in traces, metrics or JSON logs.
Incident simulationSynthetic database, retrieval and authorization faults with recorded detection.

Assurance

Release batteryLint, tests, safety evaluation, red team (70 scenarios), scans and container checks produce a readiness verdict.
